# Global instructions

## Web search
- Web search is available via the `youcom` MCP server (`youcom_you-search`). Use it for anything after your knowledge cutoff, current releases/versions, prices, news, or facts you are unsure about. Prefer searching over guessing.
- The built-in `webfetch` tool is available to read full page content after a search.
- The You.com free profile allows 100 queries/day. Avoid redundant searches; batch when possible.

## Git safety
- Do NOT run `git commit`, `git push`, amend, or rewrite history unless the user explicitly asks you to commit. Always ask before committing.
- Do not stage or commit changes as a side effect of other work.
- Keep changes minimal and focused; do not refactor unrelated code.
